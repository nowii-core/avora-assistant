# Contribuire a Avora

1. Apri una issue descrivendo il problema, il risultato atteso e un modo per riprodurlo.
2. Evita di includere dataset, checkpoint, segreti, log privati o dati personali nelle issue e nelle pull request.
3. Aggiungi test per le modifiche al server, alla persistenza o al modello.
4. Esegui `python -m unittest discover -s tests -v` prima di inviare una pull request.
5. Documenta modifiche a tokenizer, architettura, formato checkpoint e provenienza dei dati.
6. Non dichiarare prestazioni del modello senza risultati riproducibili e valutazioni su dati separati.
